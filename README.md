# Email AI Detector

**Определение писем, сгенерированных искусственным интеллектом**

![license](https://img.shields.io/badge/license-MIT-blue)
![python](https://img.shields.io/badge/python-3.9%2B-blue)

Инструмент разбирает `.eml`-письма, дробит их HTML на смысловые блоки и оценивает вероятность того, что содержимое было создано или отредактировано языковой моделью. Каждый блок сначала проходит через LLM, а затем через собственный движок, который объединяет сигналы модели со структурными аномалиями разметки и выдаёт итоговый вердикт по всему письму.

## Особенности

Анализ идёт не по одному признаку, а по совокупности сигналов. Оценка языковой модели дополняется поиском характерных для машинной генерации артефактов: неразрешённых шаблонных переменных, подозрительных комментариев в коде, чрезмерной вложенности таблиц, дублирующихся стилей и пустых ячеек.

Движок (`engine.py`) взвешивает эти сигналы, считает уверенность через дисперсию и формирует человекочитаемое объяснение — почему письмо отнесено к той или иной категории. Итоговых вердиктов три: написано человеком, смешанный текст (правки ИИ) и полностью сгенерировано ИИ. Результаты по каждому письму и по всей папке сохраняются в JSON.

## Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone <url-репозитория>
cd email_ai_detector
pip install -r requirements.txt
```

Скопируйте пример конфигурации и укажите свой API-ключ:

```bash
cp .env.example .env
```

Файл `.env` содержит следующие параметры:

```env
DEEPCODE_API_KEY=ваш_реальный_ключ
DEFAULT_MODEL=nvidia/gemma-4-31B-it-NVFP4
DRWEB_DATA_DIR=./data/raw/drweb
```

## Использование

Положите письма в формате `.eml` в папку, указанную в `DRWEB_DATA_DIR` (по умолчанию `./data/raw/drweb`), и запустите анализ:

```bash
python run.py
```

Программа пройдёт по всем письмам в папке, выведет прогресс и глобальную оценку в консоль, а подробные отчёты сохранит в `data/processed/`. Сводный результат по всем письмам попадёт в `full_analysis.json`, а разбор каждого письма — в отдельные файлы внутри `analysis_results/`.

Запуск тестов:

```bash
python -m pytest tests/
```

## Структура проекта

```text
email_ai_detector/
├── run.py                  # Точка входа: обход папки и запуск анализа
├── requirements.txt        # Зависимости проекта
├── src/
│   ├── config.py           # Настройки, ключи и пути (читаются из .env)
│   ├── analyzer.py         # Загрузка писем, разбивка HTML, вызовы LLM
│   ├── engine.py           # Взвешивание сигналов и итоговый вердикт
│   └── utils.py            # Вспомогательные функции (файлы, время, очистка)
├── tests/                  # Модульные тесты
└── data/
    ├── raw/drweb/          # Входные .eml-письма
    ├── processed/          # Результаты анализа в JSON
    └── datasets/           # Датасеты для экспериментов
```
